# Contributing to SanRemes — no CLA required

No Contributor License Agreement is required to contribute to SanRemes.
Contributions are made under the Apache License 2.0; see
[LICENSING.md](LICENSING.md). Submit only code you wrote or have the right
to contribute.

The upstream OpenMausBot CLA previously in this file granted rights to
Milind Soni for contributions to an `enterprise/` directory licensed under
the OpenMausBot Enterprise License. That directory does not exist in this
fork — it was deleted at the fork — so the upstream CLA has no scope here
and its text has been removed.
