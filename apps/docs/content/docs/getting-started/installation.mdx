## Download a released build

Choose your computer below. Each link always downloads the latest published build.

| Platform | Recommended package | Notes |
|---|---|---|
| macOS Apple silicon | [Download `.dmg`](https://github.com/SanthoshKumar020/SanRemes/releases/latest/download/SanRemes.dmg) | Signed and notarized. Drag to Applications. |
| macOS Intel | [Download `.dmg`](https://github.com/SanthoshKumar020/SanRemes/releases/latest/download/SanRemes-intel.dmg) | Signed and notarized. |
| Windows x64 | [Download installer](https://github.com/SanthoshKumar020/SanRemes/releases/latest/download/SanRemes-setup.exe) | Per-user installer; Windows signing is not yet available. |
| Ubuntu 24.04 x64 | [Download `.deb`](https://github.com/SanthoshKumar020/SanRemes/releases/latest/download/SanRemes-amd64.deb) · [AppImage](https://github.com/SanthoshKumar020/SanRemes/releases/latest/download/SanRemes.AppImage) | The `.deb` is recommended; the AppImage is portable. |
| Fedora x64 | [Download `.rpm`](https://github.com/SanthoshKumar020/SanRemes/releases/latest/download/SanRemes-x86_64.rpm) | Community-supported; install with `sudo dnf install ./SanRemes-x86_64.rpm`. |

<Callout type="warn" title="Windows SmartScreen">
  The Windows installer is not code-signed yet. Windows may show “Unknown publisher.” Verify that you downloaded it from the official SanRemes releases repository before choosing **More info → Run anyway**.
</Callout>

<Callout title="Windows install folder">
  By default the Windows app installs to `%LOCALAPPDATA%\Programs\SanRemes`, and every update goes back to the folder the installer recorded. Keep it where the installer put it: a copy moved by hand (for example from C: to D:) is left behind, and the next update lands in the recorded folder again.
</Callout>

## Install an agent CLI

SanRemes needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart SanRemes.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/SanthoshKumar020/SanRemes.git
cd SanRemes
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

SanRemes stores its application data under `~/.sanremes`. Workspaces you add are in `~/.sanremes-profiles/`; once this computer's bots have moved to My Cloud, This Mac's (or This PC's) is there too, as `default`, and `~/.sanremes` keeps the copy from before the move. On a server, see [Data and backups](/docs/self-hosting/data-and-backups) for the Docker and installer folders. Electron window and browser data use the normal per-platform application data directory.
